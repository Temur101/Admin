# Этап 8: React-админка владельца SaaS (Детальный план реализации)

## 1. Архитектурный контекст и цели этапа
Разработка полноценной веб-панели управления для владельца SaaS платформы (SuperAdmin).
Админка позволяет управлять арендаторами (Tenants), подключать и настраивать Telegram-ботов (LeadCatch и QuickBook), модерировать чеки оплаты, отслеживать финансовую и операционную аналитику (MRR, выручка, конверсии, ошибки webhook), а также конфигурировать глобальные настройки платформы и Platform Alert Bot.

## 2. Стек и библиотеки
- **Фреймворк:** React 19 + TypeScript + Vite 6
- **Стилизация:** Tailwind CSS 4 + Lucide Icons
- **Роутинг:** React Router v7 (`createBrowserRouter` / `Routes`)
- **Состояние & Кэширование данных:** `@tanstack/react-query` v5
- **Типизация:** Прямое использование схем и DTO из `@lcqb/contracts`
- **Архитектурное правило проекта:** Строго **до 300 строк на файл** (`max-lines: 300`).

## 4. Спецификация страниц и экранов

### 4.1. Авторизация (`/login`)
- Форма входа: Email/Username и пароль.
- Обработка ошибок rate limit (429) с таймером ожидания 15 минут.
- Сохранение токена в памяти / cookie, перенаправление на `/dashboard`.

### 4.2. Аналитический дашборд (`/dashboard`)
- **Финансовые KPI:**
  - `Нормализованный MRR`: расчёт по активным платным подпискам (`amount / months`).
  - `Фактическая выручка (текущий месяц)`: кассовые сборы подтверждённых чеков.
  - `Всего оплат (All-time)`: накопительный итог.
- **Операционные KPI:**
  - Счётчик активных платящих ботов vs ботов на триале.
  - Счётчик чеков в статусе `PENDING` (с подсветкой, если требуется внимание).
  - Подписки, истекающие в ближайшие 3 дня.
  - Объем лидов LeadCatch и бронирований QuickBook.
  - Ошибки доставки вебхуков за 24 часа.

### 4.3. Арендаторы (`/tenants`)
- Таблица арендаторов: имя клиента/бизнеса, контактный телефон, количество ботов, дата регистрации.
- Кнопка создания арендатора + боковая шторка/модалка: создание арендатора и первого бота.
- Деактивация арендатора (`DELETE /api/v1/tenants/:id`).

### 4.4. Боты (`/bots` и `/bots/:id`)
- **Список ботов (`/bots`):** карточки/таблица всех ботов с бейджами статуса подписки (`TRIAL`, `ACTIVE`, `GRACE`, `BLOCKED`, `SUSPENDED`).
- **Кнопка быстрого создания бота:**
  - Выбор арендатора.
  - Тип: LeadCatch или QuickBook.
  - Ввод Telegram токена бота с автоматической валидацией через API.
- **Детальная страница бота (`/bots/:id`):**
  - **Таб «Обзор»:** имя, username, инвайт-ссылка с кнопкой «Копировать», подписка, статистика.
  - **Управление статусом:** кнопки «Приостановить» (`/suspend`), «Возобновить» (`/resume`), «Удалить безвозвратно» (`?purge=true`).
  - **Таб «Шаблоны»:** каталог готовых пресетов («Учебный центр», «Барбершоп 2 мастера» и др.) с применением в один клик.
  - **Таб «Конфигурация»:**
    - Для LeadCatch: визуальный конструктор вопросов, вариантов ответов, связок DAG и сбор телефона.
    - Для QuickBook: настройка услуг (длительность, цена), мастеров/ресурсов, расписания (дни недели, часы работы), интервалов слотов.
  - **Таб «Администраторы»:** просмотр списка администраторов бота, перевыпуск инвайт-кода, отзыв прав.
  - **Таб «Диагностика»:** статус Telegram Webhook, синхронизация webhook, ручное продление подписки (+30 дней), разблокировка.

### 4.5. Очередь чеков (`/receipts`)
- Список всех `PENDING` чеков.
- Карточка чека: имя арендатора, юзернейм бота, выбранный тариф (1, 6, 12 мес), сумма в UZS, дата отправки.
- Просмотр фото чека через защищённый эндпоинт `/api/v1/receipts/:id/image` или текст заметки.
- Кнопки «Одобрить» и «Отклонить» (с обязательным указанием причины отказа для отправки в Telegram).

### 4.6. Системные настройки (`/settings`)
- Реквизиты платёжной карты (Uzcard / Humo).
- Тарифные планы (стоимость на 1, 6, 12 месяцев).
- Инструкция для клиентов по оплате и отправке чека.
- Режим технического перерыва (`maintenanceMode`).
- Настройки Telegram Alert Bot: статус подключения, кнопка «Отправить тестовое уведомление».
