# Подготовка состава репозитория

Очистка выполнена поверх версии `a885806`, содержащей исправления QuickBook и очередь LeadCatch. Она касается состава файлов и документации, а не поведения приложений.

## Что изменено

- Из текущего дерева исключены четыре набора `brag-output-*`: ролики, музыка, обложки и исходники их создания. Эти файлы не используются приложениями и настройками сборки.
- Исключена папка `audit` со старыми отчётами, скриншотами и результатами тестов. Актуальные результаты предыдущей автоматической приёмки сохранены в документации.
- Удалён отдельный `scripts/add-partial-index.sql`: создание соответствующего индекса уже входит в сохранённые миграции.
- Исторические планы и первоначальное архитектурное задание перенесены в `docs/archive` с явной пометкой об архивном статусе. Машинные ссылки заменены переносимыми, когда текущая цель существует; недоступные исторические ссылки сохранены текстом.
- Подготовлены актуальные README, оглавление документации, описание архитектуры, руководство локальной разработки и объяснение вариантов размещения на VPS/Vercel.
- В `.gitignore` добавлены генерируемые демоматериалы, старое дерево аудита и типовые файлы дампов. `.dockerignore` исключает секреты, локальные данные и лишние артефакты из будущего контекста Docker-сборки.

Удалено 83 отслеживаемых файла. До очистки 414 отслеживаемых файлов занимали около 25,6 МБ, из которых примерно 21,8 МБ приходилось на демоматериалы и 1,8 МБ — на дерево аудита. Дополнительная документация занимает небольшую часть освобождённого объёма.

После очистки текущее дерево содержит около 2 МБ отслеживаемых файлов. Установленные зависимости, сборки и история `.git` в это число не включены.

## Что сохранено

Исходники, тесты, `packages/contracts`, lockfile зависимостей, настройки проверок, шаблон окружения и все 13 миграций сохранены без изменений. Локальные базы, `uploads`, настоящие `.env`, установленные зависимости и пользовательские резервные копии не удалялись.

Перед удалением создан архив всех 414 отслеживаемых файлов вне репозитория; содержимое сверено по SHA-256 для каждого файла. Дополнительно все прежние файлы доступны в истории Git по версии `a885806`. История не переписывается: размер текущего дерева уменьшается, а старые медиа могут по-прежнему загружаться при полном клонировании истории.

Эта копия исходных файлов не является резервной копией рабочей PostgreSQL или файлов пользователя.

## Проверка очистки

- Для 310 защищённых файлов исходников, тестов, миграций, зависимостей и конфигурации подтверждено полное совпадение SHA-256 с версией до очистки.
- Все 13 миграций сохранены.
- Локальные Markdown-ссылки проверены: отсутствующих целей не найдено.
- Сборка, проверка типов, линтер, анализ зависимостей, поиск неиспользуемого кода и проверка границ тестового транспорта прошли успешно.
- Форматирование актуальной документации и `git diff --check` прошли успешно.
- Проверено исключение новых демоматериалов, результатов аудита и дампов через `.gitignore`.

Поведенческие тесты заново не запускались: код и тесты побайтно сохранены, а последняя автоматическая приёмка версии `a885806` дала 515 серверных и 272 проверки интерфейса и общих сценариев. Эти наборы частично пересекаются и не суммируются как уникальные тесты.

## Граница готовности

Репозиторий упорядочен для следующего этапа развёртывания. Готовые Dockerfile/Compose, сертификаты HTTPS, VPS и автоматические бэкапы не создавались в рамках очистки. Их настройка описана в [руководстве размещения](deployment.md).
